# Data dictionary

All return columns are log returns.  Volume is mean absolute demand, expressed
in the same wealth units as the demands.  Price columns are levels, not logs,
unless the column name says `log_price`.

## `results/series.csv`

Generated by `scripts/run_simulation.py`.  The directory is ignored by git.

| Column | Meaning |
| --- | --- |
| `step` | Step index after the burn-in |
| `price` | Price level |
| `log_price` | Natural logarithm of the price |
| `return` | Log return from the previous step |
| `volume` | Mean absolute demand |

## `results/metrics.json` and `docs/baseline_metrics.json`

| Key | Meaning |
| --- | --- |
| `seed` | Random seed |
| `n_steps` | Total simulated steps |
| `burn_in` | Discarded steps |
| `n_observations` | Returns used in the table |
| `metrics` | Six statistics and their values |
| `thresholds` | Pass criteria |
| `facts` | One row per statistic with value, criterion and pass flag |
| `all_facts_pass` | True when every row passes |

## Per-seed and per-variant files

| File | Rows | Columns |
| --- | --- | --- |
| `docs/robustness.csv` | One per seed | `seed`, six metrics, `all_facts_pass` |
| `docs/robustness_50.csv` | One per seed | Same columns |
| `docs/ablations.csv` | One per ablation and seed | `ablation`, `seed`, `pass_count`, `all_pass`, six metrics |
| `docs/sensitivity_full.csv` | One per variant and seed | `variant`, `seed`, `pass_count`, `all_pass`, six metrics |
| `docs/thresholds.csv` | One per fact and threshold | `fact`, `column`, `direction`, `threshold`, `passes`, `total`, `rate` |
| `docs/benchmarks.csv` | One per synthetic series | `series`, five price metrics, `pass_count` |
| `docs/benchmark_rates.csv` | One per benchmark | `series`, `n_series`, five pass counts, `all_five` |
| `docs/strict_criteria.csv` | One per seed | `seed`, five pass flags, `pass_count`, `all_pass` |
| `docs/null_distribution.csv` | One per statistic | `statistic`, `q05`, `median`, `q95`, `model`, `percentile` |
| `docs/sample_size.csv` | One per sample size and seed | `size`, `seed`, `pass_count`, `all_pass`, six metrics |
| `docs/phase_diagram.csv` | One per cell and seed | `activity_sigma`, `max_chartist_demand`, `seed`, `pass_count`, `all_pass`, six metrics |
| `docs/stability.csv` | One per block | `block`, `start`, `end`, `n_observations`, six metrics |
| `docs/block_ensemble.csv` | One per seed and block | `seed`, `block`, `start`, `end`, `n_observations`, six metrics, `block_pass_count` |

## Summary files

| File | Columns |
| --- | --- |
| `docs/inference.csv` | `statistic`, `point`, `mean`, `lower`, `upper` |
| `docs/price_volume.csv` | `statistic`, `value` |

The six statistics are kurtosis, return ACF at lag 1, absolute-return ACF at
lags 1 and 50, the volume-volatility correlation and the four-sigma tail ratio.
